# ¡Hola Amigos! 🦜 ספרדית לילדים

אפליקציה ללימוד ספרדית עבור ילדים ישראלים בגילאי 6-12 שעוברים לספרד. ממשק בעברית, ספרדית של ספרד (castellano), מותאמת לאייפד ולאייפון כאפליקציית ווב שמתקינים על מסך הבית (PWA).

## מה יש באפליקציה

**שני מסלולים לפי גיל**
- **קטנים (6-8)**: לומדים דרך שמע ותמונות. ההוראות מוקראות בעברית ואין צורך לקרוא או לכתוב. שירים מוקראים לשירה משותפת, והסיפורים מסופרים בקול.
- **גדולים (9-12)**: כל מה שבמסלול הקטנים, ובנוסף קריאה, הקלדה, בניית משפטים, דקדוק והטיות פעלים.

**ארבעה שלבים, 90 שיעורים (63 במסלול הקטנים)**
| שלב | תוכן |
|---|---|
| 1 · צעדים ראשונים | ברכות ונימוסים, היכרות, שיום אותיות A-Z (כולל Ñ) וצלילים מיוחדים, מספרים עד 100, צבעים (כולל התאמה בזכר ונקבה), "משפטי הצלה" לכיתה ולחצר |
| 2 · העולם שלי | משפחה, חיות, גוף ורופא, אוכל, בגדים, מזג אוויר, ימים, חודשים ועונות, רגשות ומשחקים |
| 3 · מדברים ספרדית | גופים (yo, tú…, tú/usted), el/la/un/una, ser, estar, tener, הטיות -ar/-er/-ir, פעלים חריגים (ir, querer, poder), me gusta, וסיפורים קלאסיים |
| 4 · מתקדמים | בית ועיר, תחבורה והתמצאות, שעה ושגרה (פעלים חוזרים), עבר (he comido, pretérito indefinido), עתיד (voy a…), חגים ומנהגים בספרד, שיחות מהחיים |

**סוגי תרגילים**: כרטיסי מילים עם הקראה (גם במהירות איטית), "מה שמעתם?", בחירת מילה, התאמת זוגות, תרגיל דיבור עם זיהוי קול, הקלדה עם מקשי á é ñ, בניית משפט מאריחים, השלמת הטיה, שירים במצב קריוקי וקורא סיפורים עם שאלות הבנה.

**שירים וסיפורים (נחלת הכלל בלבד)**
- שירי ילדים מסורתיים מספרד: Los pollitos dicen, Cinco lobitos, Un elefante se balanceaba, Tengo una muñeca vestida de azul, Al corro de la patata, Arroz con leche, Cucú cantaba la rana, Debajo un botón, Cumpleaños feliz.
- קלאסיקות שילדים ישראלים מכירים, מתורגמות לספרדית: הארנבת והצב, האריה והעכבר, הלפת, זהבה ושלושת הדובים, שלושת החזירונים, הברווזון המכוער, הצרצר והנמלה.
- מסורת ספרדית: El Ratoncito Pérez (קולומה, 1894), La lechera (סמניגו), חגים ומנהגים (Reyes Magos, 12 הענבים, Fallas, Tomatina) והחיים בספרד.

**מוטיבציה**: כוכבים (1-3) לכל שיעור, רצף ימים 🔥, אלבום מדבקות על כל יחידה שהושלמה, מד התקדמות כללי ולפי יחידה, ותוכי בשם לולה שמעודד את הילדים. טעות לא "פוסלת": התרגיל חוזר בסוף השיעור.

**ניהול**: כניסה עם שם משתמש וסיסמה. המנהל יכול ליצור משתמשים, למחוק אותם, לאפס סיסמה, להחליף מסלול, לאפס התקדמות ולראות את ההתקדמות של כל ילד.

> **הערה על זכויות יוצרים:** לפי הבחירה שלכם, האפליקציה לא כוללת ספרים מוגנים כמו "פילים בכל הצבעים". אם תקבלו אישור מבעלי הזכויות, אפשר להוסיף שיעור מסוג `story` בקובץ `lib/curriculum/level*.js`.

## העלאה לאוויר: Vercel + Neon (בערך 15 דקות)

### 1. מסד נתונים ב-Neon
1. נכנסים ל-[neon.tech](https://neon.tech) ופותחים פרויקט חדש. כדאי לבחור אזור באירופה, למשל Frankfurt.
2. בלוח הבקרה לוחצים על **Connect**, מסמנים **Connection pooling** ומעתיקים את מחרוזת החיבור (מתחילה ב-`postgresql://`).

### 2. העלאת הקוד ל-GitHub
```bash
cd spanish-kids
git init && git add . && git commit -m "Hola Amigos"
```
יוצרים מאגר חדש (פרטי) ב-GitHub ודוחפים אליו את הקוד.

### 3. פריסה ב-Vercel
1. ב-[vercel.com](https://vercel.com) בוחרים **Add New → Project** ומייבאים את המאגר.
2. תחת **Environment Variables** מוסיפים:

| משתנה | ערך |
|---|---|
| `DATABASE_URL` | מחרוזת החיבור מ-Neon |
| `AUTH_SECRET` | מחרוזת אקראית ארוכה, לפחות 32 תווים. אפשר ליצור אחת עם `openssl rand -base64 32` |
| `ADMIN_USERNAME` | שם המשתמש של המנהל, למשל `admin` |
| `ADMIN_PASSWORD` | סיסמה חזקה למנהל |

3. לוחצים על **Deploy**. הטבלאות במסד הנתונים והמשתמש המנהל נוצרים אוטומטית בכניסה הראשונה, כך שלא צריך להריץ שום סקריפט.

> אפשר גם לחבר את Neon ישירות מתוך Vercel דרך **Storage → Neon**. במקרה כזה `DATABASE_URL` מתווסף לבד.

### 4. התקנה על האייפד או האייפון
1. פותחים את כתובת האתר ב-**Safari**.
2. לוחצים על כפתור השיתוף ⬆️ ובוחרים **"הוסף למסך הבית"**.
3. מעכשיו האפליקציה נפתחת במסך מלא עם אייקון של לולה 🦜.

**כדי שהקול והדיבור יעבדו הכי טוב:**
- **קול ספרדי טוב יותר:** הגדרות → נגישות → תוכן מוקרא → קולות → ספרדית (ספרד), ומורידים קול "משופר" (Enhanced), למשל Mónica.
- **זיהוי דיבור:** בפעם הראשונה ש-Safari מבקש גישה למיקרופון ולזיהוי דיבור, מאשרים. אם הזיהוי לא עובד במצב מסך הבית, התרגיל עובר אוטומטית לכפתור "אמרתי!" כדי שהילד לא ייתקע. זיהוי הדיבור דורש חיבור לאינטרנט.
- **מצב שקט:** אם אין קול בכלל, בודקים שמתג ההשתקה באייפד או באייפון כבוי.

## הרצה מקומית (למפתחים)
```bash
npm install
cp .env.example .env.local   # ומעדכנים DATABASE_URL לפוסטגרס מקומי או ל-Neon
npm run dev                  # http://localhost:3000
npm run check-content        # בדיקת תקינות של תוכן הלימוד
```

## מבנה הקוד
```
lib/curriculum/level1-4.js   ← כל תוכן הלימוד (קל לעריכה ולהוספה)
lib/exercises.js             ← בניית רצף התרגילים לכל שיעור ולפי מסלול
lib/speech.js                ← הקראה, זיהוי דיבור וצלילים
components/Exercises.jsx     ← רכיבי התרגילים
components/LessonPlayer.jsx  ← ניהול השיעור, משוב, כוכבים ושמירת התקדמות
app/admin                    ← אזור הניהול
app/api                      ← התחברות, התקדמות וניהול משתמשים
```

### הוספת שיעור
מוסיפים אובייקט לרשימת `lessons` של יחידה כלשהי ב-`lib/curriculum/level*.js`. לדוגמה:
```js
{ id: 'animales-7', title: 'חיות בים', type: 'vocab', items: [
  'el delfín|הדולפין|🐬', 'la ballena|הלווייתן|🐋', 'el pulpo|התמנון|🐙',
] },
```
סוגי שיעורים: `vocab`, `phrases`, `letters`, `grammar`, `song`, `story`, `explain`. כדי להגביל שיעור לגדולים בלבד מוסיפים `tracks: ['older']`. אחרי כל שינוי מריצים `npm run check-content`.
